# 📊 BigView Treasury Ladger

A real-time, community-driven dashboard designed to track **Proof-of-Transfer (PoX)** activity, stacking rewards, and community participation metrics. This tool helps Stackers visualize their Bitcoin rewards and track the overall health of the ecosystem.

---

## 🚀 Features

* **Live Stacking Stats:** Real-time tracking of total STX locked and estimated BTC reward rates.
* **Reward Calculator:** Estimate your potential Bitcoin yield based on current stacking cycles.
* **Cycle Tracking:** Visual countdowns for current and upcoming PoX cycles (Prepare vs. Reward phases).
* **Community Leaderboard:** Highlighting the most active contributors and stacking pools.
* **Protocol Metrics:** Visualizations of burn-height, block times, and miner activity.

---

## 🛠️ Tech Stack

* **Frontend:** React / Next.js
* **Data Layer:** [Stacks API](https://www.google.com/search?q=https://docs.hiro.so/api) & [Tokenstack](https://www.google.com/search?q=https://tokenstack.io/)
* **Smart Contracts:** Clarity (for on-chain data verification)
* **Styling:** Tailwind CSS / Framer Motion
